# JalRakshak — Every drop has a story

A responsive, dark cinematic water-conservation prototype built with plain HTML, CSS, and JavaScript.

## Features
- Record local water concerns with a browser-only demo history
- Select and track water-saving pledges
- Interactive conservation learning cards
- Dashboard for reports, pledges, and lesson progress
- Cinematic intro, animated water-sphere hero, ambient lighting, and scroll reveals
- Responsive mobile navigation and reduced-motion support

## Run locally
Extract the ZIP and open `index.html` in a browser. No build step or JavaScript dependencies are required. Google Fonts load online; fallback fonts are included.

## Privacy and limitations
- Reports, pledges, and lesson progress are stored in this browser using `localStorage`.
- Reports are **not** sent to authorities, a server, or a public database.
- Sample reports are demo entries, not verified real incidents.
- Clearing browser site data may remove progress. This is a prototype, not an emergency reporting service.

## GitHub Pages
Upload these files to a GitHub repository. In repository Settings → Pages, deploy from the `main` branch and root folder. This static site keeps each visitor's progress in their own browser.
